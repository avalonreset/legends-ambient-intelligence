# Support

## Getting help

- Read the [README](README.md) quickstart and run `legends-ambient doctor`
  to check your Python environment, audio tools, and ASR availability.
- Search existing [issues](https://github.com/avalonreset/legends-ambient-intelligence/issues)
  before opening a new one.
- For community discussion, join the
  [AI Marketing Hub Pro](https://www.skool.com/ai-marketing-hub-pro) community.

## Reporting bugs

Open an issue with the bug report template: what you ran, what you expected,
what happened, your OS and Python version, and the `legends-ambient doctor`
output.

## Security issues

Do not open public issues for vulnerabilities. Email
`advisory@cto-legends.com` instead. See [SECURITY.md](SECURITY.md).
